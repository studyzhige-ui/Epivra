Epivra Windows x64 / Windows 桌面版

1. Extract the entire ZIP and double-click Epivra.exe.
   完整解压 ZIP，双击 Epivra.exe。
2. Configure your provider and API key in the browser.
   在自动打开的界面配置供应商与自己的密钥。
3. Enter a research question and approve the initial route.
   输入研究问题，确认初始研究路线。

No separate Python, Git, Node.js, database or Docker is required.
无需单独安装 Python、Git、Node.js、数据库或 Docker。
Prepare built-in Python analysis in Settings: local extraction and verification,
then enable analysis. OCR is a separate optional download and may use several GB.
设置中准备内置 Python 分析，完成本地解包与校验后启用；OCR 单独按需下载。
Keep Epivra running during preparation. Use Quit in its control window to exit.
准备期间保持运行；关闭浏览器不会退出应用，退出请使用控制窗口。
Data / 数据：%LOCALAPPDATA%/Epivra
Quit and back up this folder before replacing application files.
升级前退出应用并备份数据目录，不要删除用户数据。
Provider API calls may incur fees. The build has no publisher signature.
供应商 API 调用可能收费；当前构建没有发布者签名。
Official downloads: https://github.com/studyzhige-ui/Epivra/releases
