    使用 Epivra

    从问题开始

    写下问题与用途即可。也可补充时间范围、必读资料、读者或文档形式，未确定的部分在策略中明确。

    确认后，自主研究

    审批初始策略后，Epivra 自主搜集、分析、写作与核查，无需逐步确认。你可主动暂停或调整方向；遇到额度不足等阻断，会提示你处理。

    离开页面，研究继续

    关闭页面不会取消研究，请保持本机与后台研究服务运行。稍后回来查看成果与来源依据。

    资料与隐私

    记录与成果保存在本机。在线模型、搜索及外部工具会接收必要查询和资料内容；生成策略与研究会使用所选服务的额度。
