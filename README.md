# Deep Research Agent

一个由研究 Agent 主导、由确定性后端提供可信边界的通用深度研究项目。

这是一个全新项目，不复制 `deep-research-mcp` 的研究核心。旧项目保留为可运行的历史基线；其中经过验证的搜索、抓取、来源追踪、持久化和 MCP 接入能力，只会在明确需要时按模块重新引入。

## 核心原则

> 模型负责研究判断，代码负责安全、预算、执行和可验证性。

模型应该决定研究问题如何拆解、下一步搜索什么、哪些结果值得阅读、何时深入或转向、还缺少什么证据，以及如何组织论证。后端不替模型做这些语义判断，只验证模型提出的动作是否合法、是否超出预算、证据是否真实可追溯、引用是否闭合。

## 当前状态

项目目前只建立了章程和最小 Python 工程骨架，尚未迁移旧实现，也没有假装已经具备研究功能。完整设计边界见 [PROJECT_CHARTER.md](PROJECT_CHARTER.md)。

## 本地验证

普通 Python、venv、Conda 和 uv 都可以使用。项目不会依赖某一种环境管理器。

```bash
python -m pip install -e .
python -m unittest discover -s tests
```

## 计划中的最小闭环

1. 用户提出研究问题。
2. Planner 生成可审阅的研究计划。
3. Researcher 在预算内动态执行 search、read、note、follow-up 和 conclude。
4. Supervisor 根据证据摘要和开放缺口决定继续、深化、转向或停止。
5. Writer 与 Editor 生成符合人类行文习惯、带可追溯引用的报告。
6. 确定性审计器验证来源、引文、预算和产物完整性。

在这个闭环通过多领域真实报告验收之前，不优先增加 GUI、多租户、复杂领域类型系统或大量外围功能。
