## 最终研究报告

## 中国房地产低迷对地方政府财政收入的影响：税收、土地财政与区域脆弱性研究

### 执行摘要

2021—2025年，地方房地产五税由2.08万亿元降至1.77万亿元，仅减少3067亿元；土地出让收入却由8.71万亿元降至4.15万亿元，减少4.55万亿元。房地产相关收入占地方本级“两账”收入由52.6%降至33.9%。中等低迷情景测算财政缺口约1.23万亿元，占2025年本级“两账”收入7.0%。核心风险来自土地财政收缩，而非狭义房地产税本身。[1]

### 研究目标、口径与数据方法

#### 研究问题与“影响程度”的量化定义

本报告把“房地产低迷导致政府税收减少，对地方财政收入影响多大”拆成两个层次。第一层是**狭义税收影响**，即契税、土地增值税、房产税、城镇土地使用税、耕地占用税五项财政部列示的“土地和房地产相关税收”变化对地方一般公共预算收入的影响。第二层是**广义房地产财政影响**，在上述五税之外加入国有土地使用权出让收入，因为后者虽然不是税收、列入政府性基金预算，但在房地产下行周期中对地方政府可动用财政资源的影响远大于狭义房地产税。财政部统计口径中，房产税、城镇土地使用税、土地增值税等属于地方固定收入的重要组成部分。[2]

研究期以**2021—2025年完整年度**为主，并用2026年最新可获得数据验证当前趋势。之所以把2021年作为起点，是因为这一年土地出让收入仍处于高位，此后恰好覆盖房地产市场持续调整阶段；截至2026年9月，财政部已经公布2026年1—7月财政数据，国家统计局已公布2026年上半年房地产数据。[3]

核心指标定义如下：

[ \text{狭义房地产税依赖度} =\frac{\text{房地产五税}}{\text{地方一般公共预算本级收入}} ]

[ \text{土地财政依赖度} =\frac{\text{国有土地使用权出让收入}}{\text{地方政府性基金本级收入}} ]

[ \text{广义房地产财政暴露度} =\frac{\text{房地产五税+土地出让收入}} {\text{地方一般公共预算本级收入+地方政府性基金本级收入}} ]

“绝对财政缺口”定义为房地产相关收入相对基准情景的减少额；“收入弹性”则用房地产相关财政收入变化1%时地方本级财政收入变化的百分比衡量。

#### 数据源与优先级

本报告数据源按以下优先次序使用：财政部年度及月度财政收支数据；国家统计局房地产开发、销售数据；省级人民政府及财政厅预算执行报告；省级统计局年鉴；税务总局政策文件；自然资源部门土地市场数据。Wind、CEIC适合补齐31省长期面板，但属于商业数据库，本报告无法直接核验其订阅数据，因此不把其未公开数据作为实证主样本。

财政部完整披露了全国五项土地和房地产税以及土地出让收入，可以形成2021—2025年完全同口径全国序列。2021年地方一般公共预算本级收入111077亿元、土地出让收入87051亿元；2022年分别为108818亿元和66854亿元；2023年地方一般公共预算本级收入117218亿元、土地出让收入57996亿元；2024年分别为119266亿元和48699亿元；2025年分别为122082亿元和41518亿元。[1]

省级层面存在一个重要数据约束：各省公开预算报告通常完整公布一般公共预算、政府性基金收入，但并不都连续公布五项房地产税和土地出让收入的同口径历史序列；房地产行业产生的增值税、企业所得税更难从省级公开数据中单独分离。增值税和企业所得税还涉及中央—地方及省以下财政分享，例如公开地方预算资料可以看到增值税地方分享、企业所得税中央与地方分享后还需进一步在省以下划分。[4]因此，本报告对全国部分使用严格的五税+土地收入口径，对省级部分采用“明确公开值优先、政府性基金收入作为土地财政代理、缺失即标N/A”的原则，避免人为填补并不存在的官方数据。

#### 计量方法

基准弹性模型为：

[ \ln Y\_t=\alpha+\beta\ln X\_t+\varepsilon\_t ]

其中：

[ Y\_t=\text{地方一般公共预算本级收入}+ \text{地方政府性基金本级收入} ]

[ X\_t=\text{房地产五税}+\text{土地出让收入} ]

(\beta) 即广义房地产财政收入对地方本级“两账”收入的描述性弹性。

理想的31省面板模型应为：

[ \Delta\ln Y\_{it} =\alpha\_i+\gamma\_t+\beta\Delta\ln X\_{it} +\theta Z\_{it}+\varepsilon\_{it} ]

其中省份固定效应 (\alpha\_i) 控制长期结构差异，年份固定效应 (\gamma\_t) 控制全国性政策和宏观冲击；(Z\_{it}) 应至少包括地区GDP增长、产业结构、房地产销售额、房地产投资、中央转移支付、税收政策虚拟变量及债务负担，标准误应按省聚类。

由于公开数据无法形成31省×5年完整的房地产五税、土地出让和房地产行业共享税面板，本报告**不把残缺省级数据强行拼成“伪面板回归”**；主弹性采用全国2021—2025年的时间序列OLS，并同时报告一阶差分结果作为敏感性检验。其结果适合衡量财政暴露关系，而不能直接解释为严格因果效应。

### 全国实证结果：房地产财政冲击到底有多大

这张表给出了本研究最核心的量化答案。

**第一，若只讨论“房地产相关税收下降”，对一般公共预算的冲击明显，但没有土地财政冲击那么大。**2021—2025年房地产五税从20793亿元降至17726亿元，累计减少3067亿元，降幅约14.8%；同期地方一般公共预算本级收入反而由111077亿元增加到122082亿元，增长约9.9%。因此，房地产税减少没有造成地方一般预算收入同比例坍塌，其他税种、非税收入及经济结构变化形成了较强对冲。[1]

**第二，真正改变地方财政资产负债结构的是土地出让收入。**2021—2025年土地出让收入从87051亿元下降到41518亿元，累计减少45533亿元，降幅52.3%，约为五项房地产税减收规模的14.8倍。[1]

**第三，房地产在地方“本级两账”中的暴露度大幅下降。**五税加土地收入由2021年的107844亿元降至2025年的59244亿元，减少约4.86万亿元；其占本级一般公共预算+本级基金收入的比例从52.6%下降至33.9%，下降18.7个百分点。这既意味着地方政府正在被动降低房地产财政依赖，也意味着传统以卖地收入支持基础设施、土地整理和相关资本性支出的模式失去约束较弱的收入来源。[1]

需要特别注意：土地出让收入是**毛收入而不是净可支配收益**。其中有土地征收补偿、拆迁、土地开发等成本，因此“减少4.55万亿元”不能机械等同于地方政府少了4.55万亿元自由支配财力。相反，房地产税收入直接进入一般公共预算，其边际下降对“三保”等一般财政支出的约束更加直接。因此，本报告同时保留“狭义一般预算冲击”和“广义两账冲击”两套指标，而不把两者混为一谈。

#### 税种内部存在明显分化

2025年契税4440亿元，同比下降14.1%；土地增值税4102亿元，下降15.7%；但房产税5212亿元，同比增长10.8%，城镇土地使用税2551亿元，增长5.2%，耕地占用税1421亿元，增长3.9%。因此，“房地产低迷导致所有房地产税同步下降”的说法并不准确。[5]

原因在于税基不同。契税高度依赖房地产交易；土地增值税依赖开发销售与项目清算；房产税、城镇土地使用税则更接近存量持有或使用环节，短期受成交量下降的影响较弱。2024年房地产税制政策本身也发生调整，例如住房交易契税优惠范围扩大，这意味着契税下降既包含市场成交缩量，也包含税率政策效应，不能将全部降幅解释为房地产市场因素。[6]

由此可见，最敏感的是**交易型房地产税+土地出让金**，而不是存量环节税收。

#### 当前压力仍未结束

2026年上半年，全国房地产开发投资同比下降18.0%，新建商品房销售面积下降11.6%，销售额下降13.6%，房地产开发企业到位资金下降20.2%；东、中、西部新房销售额分别下降13.6%、11.5%和14.1%。[7]

财政端的同步信号更强。2026年1—7月，地方政府性基金预算本级收入15447亿元，同比下降24.8%，其中土地出让收入11731亿元，同比下降30.8%；与此同时地方一般公共预算本级收入仍同比增长3.3%。[3]

这构成一个重要的“自然实验式”观察：**房地产低迷首先打击基金预算和土地收入，一般公共预算的总量韧性相对更强。**换言之，地方财政当前面临的主要问题，与其说是“税收突然全面消失”，不如说是土地财政这一高弹性、资本性收入来源持续收缩，而一般预算被迫承担更多稳定公共服务与偿债功能。

### 地区差异与代表省份证据

#### 东中西部面对的是同一周期，但财政缓冲垫不同

国家统计局将江苏、浙江、福建、广东等列入东部，湖北、河南等列入中部，四川、重庆、贵州、云南等列入西部。2026年上半年东、中、西部房地产开发投资分别下降18.2%、18.7%和15.3%，新房销售额分别下降13.6%、11.5%和14.1%，说明房地产调整并不是少数省份的局部问题。[7]

但相同的房地产冲击不会产生相同的财政后果，关键取决于三个“缓冲器”：本地税源是否多元化、土地财政依赖度多高、中央转移支付和债务空间多大。

| 一般预算 vs 房地产五税 | **-0.645** | **-1.552—0.261** | 0.631 | 不显著，表明五税下降被其他一般预算收入抵消 |

计算基础为财政部2021—2025年财政数据。[1]

基准0.257的直观意义是：如果房地产相关财政收入整体下降10%，在历史同期相关关系下，本级一般预算+基金预算收入约下降2.6%，并非下降10%。原因是地方财政还有非房地产税收、非税收入和其他基金收入。

但这个估计**不能当成严格的结构性因果参数**。样本只有5个年度，土地收入和总体基金收入共同带有明显趋势，存在趋势相关；一阶差分只有4个观测，置信区间很宽。因此，在政策压力测试中，本报告不直接用0.257机械外推，而采用更透明的税种—土地分项情景模拟。

值得强调的是，狭义“五税→一般预算”回归甚至出现负点估计且统计不显著，这并不表示“房地产税减少反而增加财政收入”，而是说明2021—2025年一般公共预算被增值税、所得税、非税等其他收入变化所主导。也就是说，**只研究契税等房地产税，会严重低估房地产低迷对地方广义财政的影响；只看一般预算总收入，又会掩盖土地财政的巨大收缩。**

#### 三种低迷情景

以2025年作为基准。2025年房地产五税17726亿元，其中较敏感的交易型税种——契税和土地增值税合计8542亿元；房产税、城镇土地使用税、耕地占用税合计9184亿元；土地出让收入41518亿元。[5]

情景并不是房地产价格预测，而是**财政收入压力测试**：

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 情景 | 交易型税收冲击 | 存量型税收冲击 | 土地出让收入冲击 | 一般预算税收缺口 | 土地缺口 | 广义财政缺口 | 占2025本级“两账”收入 |
| 温和 | -10% | 0% | -10% | 854亿元 | 4,152亿元 | **5,006亿元** | **2.9%** |
| 中等 | -20% | -2% | -25% | 1,892亿元 | 10,380亿元 | **12,272亿元** | **7.0%** |
| 严重 | -35% | -5% | -40% | 3,449亿元 | 16,607亿元 | **20,056亿元** | **11.5%** |

情景幅度并非脱离历史。土地出让收入2022、2023、2024、2025年分别同比下降23.3%、13.2%、16.0%和14.7%；2026年1—7月又同比下降30.8%，因此“-25%”属于当前数据可以支持的中等压力场景，“-40%”则是尾部风险压力测试。[14]

对于用户问题“税收减少会多大程度影响财政收入”，上述模拟可以给出一个更直接的区间：

**只计房地产税，不计卖地收入**，温和、中等、严重情景分别减少一般预算收入约0.7%、1.5%和2.8%。也就是说，房地产相关税收单独下降，通常不会导致全国地方一般公共预算出现两位数级坍塌。

**加入土地出让后**，同一轮房地产低迷可以让地方本级“两账”毛收入减少约2.9%、7.0%和11.5%。因此，地方财政真正的“尾部风险放大器”是土地收入，而非五项税收。

而且上述结果仍然可能**低估一般预算端的房地产风险**，因为尚未计入房地产开发、建筑、中介以及相关上下游企业贡献的增值税、企业所得税和个人所得税地方分享部分。公开财政统计并不连续披露“房地产行业产生的共享税地方份额”，因此无法可靠加入全国省级面板。

另一方面，广义缺口又可能**高估可支配财力损失**，因为土地出让毛收入本身带有征拆、整理等成本。两种偏差方向相反，所以最合理的政策监测方式不是使用一个单一数字，而是同时监测“一般预算税收缺口”和“基金预算土地缺口”。

#### 敏感性结论

无论采用水平值弹性0.257、变化率弹性约1.0，还是自下而上的情景模拟，结论方向一致：

**房地产财政收入变化对地方财政的影响不是1∶1传导；一般公共预算具有较强缓冲，但政府性基金预算高度暴露于土地市场。房地产持续低迷真正危险的不是契税减少几个百分点，而是土地收入长期处于峰值的一半以下，同时地方债务、基础设施和公共服务支出具有刚性。**

### 地方财政脆弱性评分与风险分层

#### 脆弱性指数设计

为避免把“土地收入规模大”简单等同于“财政风险高”，本报告构建一个筛查型地方财政脆弱性指数 (VFI^\*)，只用于横向比较，不属于官方债务风险评级。

[ VFI^\* =0.50L+0.30F+0.20D ]

其中：

**土地暴露 (L)，权重50%**：以2025年土地出让收入/地方一般公共预算收入衡量；60%及以上视为极高暴露并封顶100分。

**财政自给风险 (F)，权重30%**：财政自给率超过50%的地区赋较低风险值30，其余样本赋75。2025年超过50%的主要包括上海、北京、广东、浙江、江苏、天津、福建、山东、山西。[12]

**债务与财政缓冲 (D)，权重20%**：根据公开省级财政债务比较做分档。2025年的区域债务研究指出，贵州、云南、辽宁、广西等省份债务体量仍处相对高位，同时经济大省和四川也承担较大的地方政府债务规模。[15]

六个数据较完整代表省份的筛查结果如下。土地出让收入使用2025年公开省份汇总数据。[11]

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 省份 | 2025土地收入/一般预算 | 财政自给状况 | (VFI^\*) | 风险档 | 核心原因 |
| 四川 | 53.8% | &lt;50%组 | **79.3** | 高 | 土地暴露高、一般预算自给能力相对弱、债务规模较大 |
| 湖北 | 54.9% | &lt;50%组 | **78.3** | 高 | 土地收入相当于一般预算一半以上，财政缓冲弱于沿海强省 |
| 江苏 | 54.5% | &gt;50%组 | **63.4** | 中高 | 卖地绝对规模全国最高，但产业与税基形成较强缓冲 |
| 浙江 | 49.0% | &gt;50%组 | **58.8** | 中 | 土地财政暴露仍高，但财政自给能力较强 |
| 福建 | 40.7% | &gt;50%组 | **49.9** | 中低 | 土地/基金收入明显下降，但一般预算保持增长 |
| 广东 | 17.4% | &gt;50%组 | **30.5** | 相对低 | 土地收入相对一般预算规模较低，税源较多元 |

江苏2024年土地出让收入约7270亿元，2025年降至约5589亿元，说明即使经济强省也无法完全回避土地市场下行冲击；浙江2025年土地收入约4346亿元，依旧是全国最高梯队。[16]

这里需要区分两类“高风险”。

第一类是**房地产暴露型风险**，典型如湖北、四川，以及一定程度上的江苏、浙江：土地收入占自身财政资源比重较高，楼市和土地市场变化容易迅速传导至基金预算。

第二类是**综合财政脆弱型风险**，贵州、云南、广西等地更值得持续监测，原因不只是房地产，而是较低财政自给能力与较大债务压力同时存在。近期省级债务比较也把贵州、云南、广西等列为债务体量相对较高地区。[15]对这些地区而言，即使土地收入绝对规模未必高于江苏浙江，房地产低迷造成的边际财政冲击也可能更难吸收。

因此，**高风险监测组**可分为贵州、云南、广西等综合财政脆弱地区，以及湖北、四川等本报告样本中的高房地产暴露地区；**相对低风险组**则包括广东，以及财政自给能力较强的上海、北京。这里的“低风险”仅是相对概念，并不意味着土地市场调整对其财政完全没有影响。2025年各省财政数据显示，上海、北京、广东仍属于财政自给能力领先地区。[12]

### 政策含义与风险缓释路径

房地产财政调整不是简单通过“刺激卖地”即可解决的问题。2021—2025年土地收入下降超过一半，而2026年1—7月仍同比下降30.8%，这意味着政策目标应从“恢复旧土地财政”转向“用转移支付、稳定税基和债务重组争取时间，同时建立更可持续地方税源”。[17]

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 政策 | 时间维度 | 可行性 | 财政作用 | 主要副作用/约束 |
| 对高脆弱地区增加均衡性与县级基本财力转移支付 | 短期 | 高 | 直接填补“三保”财力缺口，避免房地产冲击转化为基本公共服务风险 | 若长期固化，可能削弱地方拓税源和压支出的激励 |
| 把房地产财政风险纳入转移支付公式 | 短中期 | 中高 | 根据土地收入下降、财政自给率和债务负担动态倾斜 | 需防止地方通过夸大缺口获取补助 |
| 压缩低效基建和非刚性支出，优先保障“三保”、存量项目收尾 | 短期 | 高 | 直接降低现金流需求 | 地方投资下降可能对经济产生顺周期收缩效应 |
| 利用债务置换延长高成本债务期限 | 短中期 | 高 | 把短期流动性压力转为较长期偿债安排 | 只能改变期限和利息负担，不能创造新的永久财政收入 |
| 土地储备和存量土地盘活以“缩量提质”为主 | 中期 | 中 | 减少无效供地，改善土地收入质量 | 若政府集中高价收储，可能把房地产风险进一步转移到公共部门资产负债表 |
| 完善消费税、地方附加税等稳定地方税源 | 中长期 | 中 | 降低地方财政对一次性土地收入依赖 | 地区消费能力差异可能扩大区域财力分化，需要转移支付再平衡 |
| 推动房地产税制由交易环节向保有环节逐步优化 | 长期 | 中低 | 形成更稳定、与存量资产相关的地方收入 | 房价调整期若过快推进，可能进一步压低居民住房需求和资产价格预期 |
| 建立“土地收入不得作为永久性经常支出基础”的预算约束 | 长期 | 中高 | 从制度上降低顺周期财政行为 | 转型初期会限制地方基础设施投资和自主支出空间 |

短期政策重点应是**保基本财政能力，而不是保土地价格**。2025年地方一般公共预算支出244361亿元，而本级收入仅122082亿元，地方财政已经高度依赖中央转移支付、调入资金和债务工具维持支出体系；2025年中央对地方转移支付收入超过10万亿元。[18]在房地产财政继续调整时，均衡性转移支付和县级基本财力保障比单纯扩大地产刺激更能直接降低财政尾部风险。

中期则应将房地产周期与债务管理结合。土地收入下降最危险的情况并不是当年少卖一些地，而是过去基于较高土地收入预期形成的建设投资、专项债项目、城投现金流在收入下降后仍需要持续付息和运营。因此债务置换的目标应是**降低利息和期限错配**，而不是以新融资延续缺乏经营现金流的投资。

长期改革的关键是**改变地方财政的收入性质**：土地出让属于一次性资产变现，更适合支持一次性资本项目，而不适合作为永久性公共服务扩张的收入基础。房产税、地方附加税、消费税地方分享等相对稳定税源则更适合匹配教育、社保、公共卫生等经常性责任。不过，在房地产价格和居民资产负债表仍调整的阶段，任何新增住房持有环节税负都应渐进推进，避免财政改革反过来强化房价下行。

政策传导与风险缓释可以概括如下：

房地产销售与价格下行

开发商现金流和拿地意愿下降

住房交易量下降

土地出让收入下降

契税下降

土地增值税及房地产企业相关税基走弱

地方政府性基金预算收缩

地方一般公共预算房地产税收减少

基建与土地整理资金减少

一般财政可用财力承压

专项债/城投项目现金流压力

三保与公共服务支出压力

地方债务风险上升

中央转移支付

债务置换与期限延长

压减低效与非刚性支出

地方税源改革

土地财政改革与存量盘活

缓释短期流动性风险

降低长期土地财政依赖

### 讨论、数据缺口与关键图表说明

#### 研究结论的正确解读

如果问题被严格限定为“**房地产相关税收下降**到底少了多少地方一般预算收入”，答案比通常印象温和：2021—2025年五项房地产税累计减少约3067亿元，而地方一般公共预算本级收入同期增加约1.10万亿元。房地产税依赖度从18.7%降至14.5%。[1]

但如果问题是“**房地产低迷对整个地方财政体系的影响**”，答案明显更严重：同期土地出让收入减少约4.55万亿元，五税+土地收入减少4.86万亿元，房地产广义收入占地方本级“两账”的比重从52.6%降至33.9%。2026年1—7月土地出让收入仍下降30.8%，说明土地财政调整并未结束。[17]

因此，本报告给出的量化区间是：

|  |  |  |  |
| --- | --- | --- | --- |
| 衡量对象 | 温和 | 中等 | 严重 |
| 房地产税减少对地方一般预算收入的直接冲击 | **约0.7%** | **约1.5%** | **约2.8%** |
| 房地产税+土地出让减少对地方本级“两账”毛收入冲击 | **约2.9%** | **约7.0%** | **约11.5%** |
| 2021—2025实际广义房地产相关收入累计降幅 | colspan | **约45.1%** |  |
| 2021—2025土地出让收入累计降幅 | colspan | **约52.3%** |  |

这里最值得关注的政策判断是：**全国层面不存在“契税少收就导致地方财政崩塌”的简单线性关系；真正的财政脆弱性来自土地收入骤降、税基偏窄、债务偿付和刚性支出四者叠加。**

#### 尚缺失的数据与替代方案

第一，**31省房地产五税的完整2021—2025面板缺失**。财政部有全国值，但部分省财政厅只在决算附件中披露具体税种，而且文件格式和口径不统一。替代方案是从Wind“地方财政税种”、CEIC省级财政数据库，或逐省财政决算Excel附件抓取契税、土地增值税、房产税、城镇土地使用税和耕地占用税，然后形成155个省年观测。

第二，**房地产行业增值税和企业所得税地方实际留成缺失**。财政部公开数据通常按税种而非“行业×中央地方归属”发布，省以下分享规则还会产生差异。因此，本报告狭义税收冲击不包括这一块，整体上偏保守。

第三，**土地出让毛收入与净收益之间缺乏统一年度省级公开序列**。土地收入下降并不等于同额净财政损失。最优替代方案是配合政府性基金决算中的国有土地使用权出让收入安排支出、征地拆迁补偿、土地开发支出，计算：

[ \text{土地净财政贡献} =\text{土地出让收入} -\text{征拆及土地开发相关成本} ]

第四，**隐性债务和城投平台真实偿债压力无法完全由法定地方政府债务余额刻画**。因此，本报告的VFI\*适用于财政脆弱性筛查，不应解释为债务违约概率。

第五，正式的31省地图热力图需要完整省级指标矩阵。本报告已提供代表省份的空间热力示意；完整研究版本应在补齐上述面板后，对31省按相同VFI公式重估，而不应给缺数据省份主观填分。

综合上述官方数据、弹性估计和压力测试，本研究的中心结论可以压缩为一句话：**房地产低迷对地方一般预算的直接“税收冲击”目前大体是几个百分点以内的问题，但把土地出让、债务与刚性支出纳入后，它可以演变为占地方本级财政资源约7%甚至超过10%的系统性财力缺口；因此地方财政风险的核心已从“房地产税收下降”转向“土地财政退潮后的收入结构重构”。**[19]
